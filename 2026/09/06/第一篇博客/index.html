第一篇博客

Hexo本地博客部署完整笔记

1.环境准备

  1. 安装 Node.js（提供npm包管理器）
  2. 安装 Git（用于初始化模板、后续部署上传）
  3. npm全局安装hexo命令行工具

2.新建博客项目

  1. 创建空文件夹，例如E:\MyBlog，进入该文件夹
  2. 在文件夹地址栏输入powershell打开终端

项目文件夹就是hexo博客项目，包含配置、文章、主题全部资源。

3.本地预览

浏览器访问：http://localhost:4000

  • 仅本机可以访问，外网打不开
  • 修改文章保存后页面自动刷新
  • Ctrl + C终止服务器，关闭终端服务也会停止

4.新建&撰写博客文章

生成文件路径：source\_posts\第一篇博客.md

  1. 文件最上方---包裹的是Front‑matter头部元信息，不可删除
  1. 正文写在第二个---下方，支持标题、列表、加粗、图片、链接等Markdown语法。
  2. 保存后，本地预览页面自动更新查看效果。

5.核心命令速查表

命令 简写 功能
hexo server hexo s 启动本地预览服务器
hexo generate hexo g 编译生成静态网页，输出到public文件夹
hexo deploy hexo d 部署上传网页到网络仓库
hexo new post “标题” 无 新建博客文章

6.后续上线简要流程

  1. 安装git部署插件：npm install hexo‑deployer‑git --save
  2. 修改根目录_config.yml底部deploy配置，填入github仓库地址
  3. hexo g生成网页 → hexo d上传，完成公网博客发布

关键注意点

  1. 所有操作终端必须处于博客项目根目录（例：PS E:\MyBlog>）
  2. yml配置文件冒号后面必须带空格，格式错误直接报错
  3. 头部---标记不能删除，否则Hexo识别不到文章元数据
  4. 启动hexo s不要关闭终端窗口，关闭就停止预览服务
